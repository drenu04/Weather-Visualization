# Weather Data Visualization & Trend Analysis

This MATLAB project visualizes daily average temperatures for selected cities, using real weather data. It helps detect patterns using:

- Daily temperature plots  
- 7-day moving average smoothing  
- Polynomial trendlines for long-term trends  

## Files

- `cities.csv` — Weather data with columns: `date`, `city_name`, `daily_avg_temp`
- `moving_average_temperature_plot.m` — Plots daily temperatures + 7-day moving average
- `polynomial_trendline_temperature_plot.m` — Fits a 3rd-degree polynomial to highlight trends
